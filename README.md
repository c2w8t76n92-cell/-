# 進興宮｜祥和祈安植福禮斗法會網站

這是一個可直接部署到 GitHub Pages 的靜態網站，使用 HTML、CSS，無需建置工具或伺服器。

## 檔案
- `index.html`：網站首頁
- `assets/hero-background.jpg`：主視覺背景（使用提供的第二張圖片）
- `assets/法會資訊海報.jpg`：法會資訊海報（使用提供的第一張圖片）

## 發布到 GitHub Pages
1. 登入 GitHub，建立一個新的 repository（例如 `jinxing-temple-ceremony`）。
2. 將此資料夾中的 `index.html`、`assets` 資料夾與 `README.md` 上傳至 repository 根目錄。
3. 在 repository 進入 **Settings → Pages**。
4. 在 **Build and deployment** 選擇 **Deploy from a branch**。
5. Branch 選 `main`，資料夾選 `/(root)`，按 **Save**。
6. 等待 GitHub Pages 部署完成，Pages 頁面會顯示公開網址。

## 上線前建議確認
- 請主辦單位確認日期、報名截止日、電話、地址與各項金額是否仍正確。
- Google 表單需確認已開放目標報名者填寫。
- 若之後要更換背景或海報，替換 `assets` 中對應圖片，並保持檔名不變即可。
